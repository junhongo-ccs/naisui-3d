# naisui-3d

国土交通省 PLATEAU の **内水浸水想定区域モデル** を、建物・地形と重ねて 3D で見るビューアです。
PC・スマホのブラウザで動き、Meta Quest のブラウザでは VR に入れます。

[naisui](https://github.com/junhongo-ccs/naisui)（品川区 中延・二葉の内水氾濫 PoC）の兄弟プロジェクトです。

## 表示しているもの

| レイヤー | 出典 | 形式 |
|---|---|---|
| 内水浸水想定区域（浸水深で色分け） | PLATEAU `ifld` | 3D Tiles (b3dm) |
| 建物 | PLATEAU `bldg`（LOD2 テクスチャ付き、無ければ LOD2 テクスチャなし、LOD1） | 3D Tiles (b3dm) |
| 地形 | 地理院タイル 標高タイル（`dem_png`） | PNG 標高タイル |
| 背景地図 | 地理院タイル（航空写真・淡色地図・標準地図） | XYZ タイル |
| 目印（駅・寺社・海岸など） | 国土地理院 地名検索 | ピン |
| 避難所 | 国土地理院 指定避難所データ | ピン |

今の公開版は **鎌倉市だけ** を表示します（VR で別の市へ迷い出ないように）。
対象の市は `src/config.ts` の `ONLY_CITY` で決めます。`null` にすると、PLATEAU に内水浸水想定区域モデルがある **28 市町村** すべてを選べます（目印・避難所のピンは、データを作った市だけ）。
API キーやアカウントは要りません。

### Google 3D で見る（試験中、`google-3d` ブランチ）

Google Map Tiles API のキーがあると、地形と PLATEAU の建物の代わりに、Google の Photorealistic 3D Tiles（地面・建物・木が一つになった写真の 3D）を読みます。浸水・ピン・VR の操作は同じです。
PLATEAU の建物は遠くから見ても細かいタイルを読むので重く、鎌倉市の最初の画面で 60 秒たっても読み終わりません（建物だけで 60 MB 以上）。Google は粗いタイルから読むので、約 20 秒・7 MB で読み終わります（2026-10-30、同じ回線での比較）。

`.env`（git に入らない）にキーを書きます。キーが無ければ、今までどおり地理院の地形と PLATEAU の建物で動きます。

```
VITE_GOOGLE_MAPS_API_KEY=...
```

キーの扱い（[kosugi_3Dmap](https://github.com/junhongo-ccs/kosugi_3Dmap) と同じ方針）:

- キーは公開ページの JavaScript に入るので、見られる前提で扱う。`.env` はコミットしない
- 本番用と開発用でキーを分ける。本番用は公開 URL、開発用は `localhost` の HTTP リファラーだけを許可する
- キーで使える API は Map Tiles API に絞る
- Google Cloud で予算アラートとクォータ上限を設定する
- 画面の出典に、表示中のタイルの提供元（Google と各データ提供者）を出す（`getAttributions()`）

浸水深の色は「水害ハザードマップ作成の手引き」の配色に合わせています。
自治体独自の区分（`uro:rankOrg`、例: 0.2m以上0.3m未満）がある場合はそちらで色分けし、標準区分の色の間を補間します。

## 使い方

```bash
npm install
npm run dev
```

`http://localhost:5173/` を開きます。URL の `?base=photo|pale|std` で背景地図を、`ONLY_CITY` が `null` のときは `?city=14204` で市町村（市区町村コード）を指定できます。

| 操作 | PC | スマホ |
|---|---|---|
| 回転 | 左ドラッグ | 1 本指ドラッグ |
| 移動 | 右ドラッグ | 2 本指ドラッグ |
| ズーム | ホイール | ピンチ |
| 浸水深を見る | クリック | タップ |
| ピンの説明を開く・閉じる | ピンをクリック | ピンをタップ |

### Quest で見る

WebXR は HTTPS が必要です。

- **公開版**：GitHub Pages（`main` に push すると `.github/workflows/deploy.yml` が公開）を Quest のブラウザで開き、ENTER VR を押す。
- **開発中**：`npm run dev:https` で LAN に公開し、Quest から `https://<PCのIP>:5173/` を開く（自己署名証明書の警告を許可する）。

VR に入ると、地図で見ていた中心の地面に立ちます。左手の上に市の地図（赤い矢印が自分の位置と向き）と操作説明が出ます。
市の浸水想定区域の外側 300 m より先と、高さ 2,000 m より上には動けません。

| コントローラー | 動き |
|---|---|
| 左スティック | 見ている方向に移動（速さは地面からの高さに比例。地上は 15 m/s） |
| 右スティック 左右 | 45° ずつ向きを変える |
| 右スティック 上下 | 上昇・下降 |
| トリガー（押しながら） | 5 倍速 |
| 右手で浸水域を指す | その地点の上に想定浸水深を表示（ボタン不要。ハンドトラッキングでも可） |
| 右手でピンを指して右トリガー | 目印・避難所の説明を開く・閉じる（ピンを指している間、右トリガーは加速にならない） |
| A ボタン | 水面を想定浸水深まで上げる／戻す（パネルの「水面を想定浸水深まで上げる」と同じ） |
| 右グリップ | 市町村の一覧（`ONLY_CITY` が `null` のときだけ。指してトリガーで移動） |
| X ボタン | 診断ボード（エラー、入力、指している先）。エラーが出ると自動で開く |
| Y ボタン | スタート地点に戻る |
| B ボタン | VR を終了して地図の画面に戻る |

水面は浸水深の区分の上限まで上げます（「0.5m未満」なら 0.5m）。「3m以上」のように上限の無い区分は下限まで上げます。

## データ一覧の更新

`src/data/cities.json` は PLATEAU データカタログ API から作っています。PLATEAU が更新されたら作り直してください。

```bash
npm run catalog
```

目印と避難所のピンは `src/data/places/<市区町村コード>.json` で、`scripts/build-places.mjs` が国土地理院の API から作ります。目印にする場所の名前は、スクリプトの `LANDMARKS` に市ごとに書きます。

```bash
node --use-system-ca scripts/build-places.mjs 14204
```

## 注意

- 内水浸水想定区域は、自治体が想定した雨（多くは想定最大規模降雨）での**シミュレーション結果**です。実際の浸水や、今の雨での予測ではありません。
- 避難の判断には、自治体の公式ハザードマップと気象・避難情報を使ってください。
- 避難所は、市町村が国土地理院に登録した「指定避難所」です（鎌倉市は災害の種類ごとの「指定緊急避難場所」を公開していません）。最新でない場合があります。開設状況などは市町村に確認してください。
