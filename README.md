# naisui-3d

鎌倉市の中心部で、**内水氾濫（大雨で下水道や水路があふれる浸水）の想定**を、写真の 3D の街に重ねて見るビューアです。
PC・スマホのブラウザで見られ、Meta Quest では VR で街の中を歩けます。
解説のピンを開くと、その場所が浸水しやすい理由、過去の被害、市の対策が読めます。

**公開版**: https://junhongo-ccs.github.io/naisui-3d/

[naisui](https://github.com/junhongo-ccs/naisui)（品川区 中延・二葉の内水氾濫 PoC）の兄弟プロジェクトです。

## 見られるもの

- **浸水想定**：国土交通省 PLATEAU の内水浸水想定区域モデル。浸水深で色分けしています（「水害ハザードマップ作成の手引き」の配色）。
- **街の 3D**：Google の Photorealistic 3D Tiles（地面・建物・木が一つになった写真の 3D）。
- **範囲**：北鎌倉・円覚寺〜材木座、長谷・大仏〜鎌倉宮。VR で迷わないように、ここだけを読み込みます。
- **ピン**
  - 目印（黒い札）：駅、寺社、若宮大路、海岸など 16 か所
  - 避難所（緑の家）：国土地理院の指定避難所データ
  - 解説（青い i）：4 か所。下の表のとおり
- **VR**：出発点は若宮大路。左手に、自分を中心に周り約 800 m の地図（赤い矢印が自分の位置と向き）と操作説明が出ます。地図の解説・目印の点を右手で指すと、その場所へ移動できます。

| 解説のピン | 札に書いてあること |
|---|---|
| 鎌倉の中心部と浸水 | 谷戸に降った雨が低地に集まる地形、内水氾濫のしくみ、この色が想定であること、1990 年・2004 年の被害 |
| 若宮大路・小町 | 2025 年 9 月（台風 15 号）の床上浸水、2026 年 9 月（台風 25 号）の冠水、若宮大路の地下の貯留管の計画 |
| 由比ガ浜の海沿い | 海沿いが高くその内側が低い地形、潮位や川の水位の影響、防潮扉、ゲートポンプや調整池の計画 |
| 長谷・稲瀬川 | 2004 年の浸水、下水道管の改築の計画（対策後も浸水はゼロにならないこと） |

解説の札は「地形」「しくみ」「この色（想定）」「実際の被害（記録）」「これからの対策」に分けています。シミュレーションの結果と、実際にあった被害を混ぜないためです。どの札にも出典と、その場所のふだんの写真（Wikimedia Commons）を入れています。

## 使い方

### PC・スマホ

公開版を開くだけです。アカウントやキーは要りません。

- スマホは横向きで見ます。縦に持っていると「横向きにしてご覧ください」と出ます（Android では、全画面・横向きに切り替えるボタンも出ます）。
  - チャットワークや LINE などのアプリの中でリンクを開くと、スマホを横にしても画面が回りません。アプリのメニューから Safari や Chrome で開き直してください。「縦のまま見る」を押せば、縦のままでも見られます。
- スマホではホーム画面に追加できます。ホーム画面のアイコンから開くと、アドレスバーなどが消えて全画面・横向きで見られます。
  - 右上の「ホーム画面に追加」を押します（× で消すと、次からは出ません）。
  - iPhone は、Safari の共有ボタン（□に↑）→「ホーム画面に追加」で追加します（ボタンを押すと、この案内が出ます）。
  - Android で右上のボタンが出ないときは、Chrome のメニュー（︙）→「ホーム画面に追加」でも追加できます。
- 画面下の ENTER VR のボタンは、VR に入れる機器（Quest のブラウザ）でだけ出ます。

| 操作 | PC | スマホ |
|---|---|---|
| 回転 | 左ドラッグ | 1 本指ドラッグ |
| 移動 | 右ドラッグ | 2 本指ドラッグ |
| ズーム | ホイール | ピンチ |
| 浸水深を見る | 色の付いた所をクリック | タップ |
| ピンの札を開く | ピンをクリック | ピンをタップ |
| 札を閉じる | 札の右上の × | 札の右上の × |
| 札を動かす | 札の上部（白い棒のあたり）をドラッグ | 札の上部をドラッグ |

札を開いている間は、回転だけができ、移動とズームはできません。札を閉じると動けます。
左上のパネルで、浸水の表示、色の濃さ、「水面を想定浸水深まで上げる」を切り替えられます。
水面は浸水深の区分の上限まで上げます（「0.5m未満」なら 0.5 m）。「3m以上」のように上限の無い区分は下限まで上げます。

### Quest（VR）

1. Quest のブラウザで公開版を開く。
2. 画面下のボタンが「読み込み中…」から「ENTER VR」に変わるまで待つ（速い回線で 40 秒ほど）。VR の出発点から見える建物まで読み終えてから押せるようにしています。
3. ENTER VR を押す。若宮大路（小町二丁目のあたり）の道路に、鶴岡八幡宮の方を向いて立ちます。

| コントローラー | 動き |
|---|---|
| 左スティック | 見ている方向に移動（速さは地面からの高さに比例。地上は 15 m/s） |
| 右スティック 左右 | 45° ずつ向きを変える |
| 右スティック 上下 | 上昇・下降 |
| トリガー（押しながら） | 5 倍速 |
| 右手で浸水域を指す | その地点の上に想定浸水深を表示（ボタン不要。ハンドトラッキングでも可） |
| 右手でピンを指して右トリガー | 目印・避難所・解説の札を開く |
| 札の右上の × を指して右トリガー | 札を閉じる |
| 札の上部を指して、右トリガーを押したまま手を動かす | 札をつかんで動かす。離した所に残るので、札を出したまま周りを見られる |
| A ボタン（押したまま） | 水面が上がる（3 秒で想定浸水深まで。離した所で止まる） |
| B ボタン（押したまま） | 水面が下がる |
| 左手の地図の解説・目印の点を右手で指して右トリガー | その場所へ移動（少し手前の上空に、その場所の方を向いて着く） |
| X ボタン | 診断ボード（エラー、入力、指している先、タイルの読み込み状況、スクリーンショットの撮り方） |
| Y ボタン | 出発点に戻る |
| Meta ボタン長押し | VR を終える（Quest のホームに戻る）。誤って押さないよう、コントローラーのボタンには割り当てていない |

- 札を開いている間は、向きを変える（右スティック左右、頭を回す）ことだけができ、移動・上昇・下降・出発点に戻る（Y）はできません。札の × で閉じると動けます。
- ピンや札を指している間は、右トリガーで加速しません。
- 表示している範囲の外側 100 m より先と、高さ 2,000 m より上には動けません。
- 地面より下にも行けません。下降は地面で止まり、上り坂では地面に沿って上がります。木や橋の下をくぐっても、その上には乗りません。
- ピンのラベルと札は、いつも直立して自分の方を向きます。頭を傾けても一緒には回りません。
- スクリーンショットは、右手の Meta ボタンを押したまま右トリガーを引きます。

## 開発

```bash
npm install
npm run dev         # http://localhost:5173/
npm run dev:https   # LAN に公開（自己署名 HTTPS）。Quest から https://<PCのIP>:5173/ を開く
npm run build       # 型チェック + ビルド → dist/
npm run typecheck
```

テストはありません。変更したら `npm run typecheck` をして、ブラウザで実際に表示して確かめます。
`main` に push すると、GitHub Actions（`.github/workflows/deploy.yml`）がビルドして GitHub Pages に公開します。

### Google のキー

街の 3D には Google Map Tiles API のキーが要ります。

- **開発中**：`.env`（git に入らない）に開発用のキーを書きます。
- **公開版**：GitHub の Actions secret `VITE_GOOGLE_MAPS_API_KEY`（本番用のキー）を、`deploy.yml` がビルドに渡します。

```
VITE_GOOGLE_MAPS_API_KEY=...
```

キーが無ければ、地理院の地形と PLATEAU の建物で動きます（下の「データ」の表を参照）。

キーの扱い（[kosugi_3Dmap](https://github.com/junhongo-ccs/kosugi_3Dmap) と同じ方針）:

- キーは公開ページの JavaScript に入るので、見られる前提で扱う。`.env` はコミットしない。
- 本番用と開発用でキーを分ける。本番用は `https://junhongo-ccs.github.io/*`、開発用は `localhost` の HTTP リファラーだけを許可する。
- キーで使える API は Map Tiles API に絞る。
- Google Cloud でクォータ上限を設定している。今は 3D Tiles root requests を 1 日 30 回にしている。
  - ページを 1 回開くと 1 回と数える。
  - 開発用のキーも同じ枠を使う。
  - 31 回目からは、その日は Google の 3D が出ない。
- 画面の出典に、表示中のタイルの提供元（Google と各データ提供者）を出す。

**Google にした理由**：PLATEAU の建物は遠くから見ても細かいタイルを読むので重く、Quest では建物が出ませんでした。
鎌倉市の最初の画面で比べると、PLATEAU は 60 秒たっても読み終わりませんでした（建物だけで 60 MB 以上）。Google は粗いタイルから読むので、約 20 秒・7 MB で読み終わりました（2026-10-30、同じ回線）。

### 設定（`src/config.ts`）

| 名前 | 内容 | 今の値 |
|---|---|---|
| `ONLY_CITY` | 表示する市（市区町村コード）。`null` にすると、PLATEAU に内水浸水想定区域モデルがある 28 市町村を選べ、`?city=<コード>` も効く | `'14204'`（鎌倉市） |
| `AREA` | 市の中で見せる範囲（地面・浸水・ピン・手の地図・VR で動ける範囲がこれに従う） | 鎌倉市の中心部 |
| `VR_START` | VR の出発点と向き。道路の中心線の座標で決める（地名検索の点は建物の中にあることがある） | 若宮大路から八幡宮の方 |

URL の `?base=photo|pale|std` で背景地図を切り替えられます（Google のキーが無いときだけ）。

## データ

| レイヤー | 公開版（Google のキーあり） | キーなし |
|---|---|---|
| 内水浸水想定区域 | PLATEAU `ifld`（3D Tiles） | 同じ |
| 地面・建物・木 | Google Photorealistic 3D Tiles | 地形：地理院タイル 標高タイル（`dem_png`）と背景地図<br>建物：PLATEAU `bldg`（LOD2 テクスチャ付き、無ければ LOD2、LOD1） |
| VR の左手の地図 | 地理院タイル（淡色地図） | 同じ |
| 目印 | 国土地理院 地名検索・逆ジオコーダー・標高 API | 同じ |
| 避難所 | 国土地理院 指定避難所データ | 同じ |
| 解説 | 鎌倉市の下水道計画・雨水管理総合計画、報道、国土地理院の標高 | 同じ |

| ファイル | 中身 | 作り方 |
|---|---|---|
| `src/data/cities.json` | 28 市町村のタイルセットの URL・中心・ジオイド高 | `npm run catalog`（PLATEAU データカタログ API から） |
| `src/data/places/<コード>.json` | 目印と避難所（町名・標高付き） | `node --use-system-ca scripts/build-places.mjs 14204`（国土地理院の API から。目印の名前はスクリプトの `LANDMARKS` に書く） |
| `src/data/stories/<コード>.json` | 解説のピンの文・出典・写真 | 手で書く |
| `public/photos/` | 解説の写真（幅 1000 px に縮めたもの） | Wikimedia Commons から |

解説や写真を足すときの決まり:

- 想定（シミュレーション）と記録（実際の被害）を別の項目に書き、どちらにも出典を付ける。報道だけが出典のことは「（報道）」と書く。
- 写真は、自由なライセンス（CC0・CC BY・CC BY-SA など）のものか、許可を取ったもの・自分で撮ったものだけ使う。札と README に撮影者とライセンスを書く。市のサイトの写真や、報道・SNS の写真は使わない。

## 注意

- 内水浸水想定区域は、市が想定した最大規模の雨での**シミュレーション結果**です。実際の浸水や、今の雨での予測ではありません。
- 避難の判断には、市の公式ハザードマップと気象・避難情報を使ってください。
- 避難所は、市町村が国土地理院に登録した「指定避難所」です。最新でない場合があるので、開設状況などは市町村に確認してください。鎌倉市は、災害の種類ごとの「指定緊急避難場所」を公開していません。
